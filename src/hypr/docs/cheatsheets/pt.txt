Hyprland Cheatsheets
====================

Atalhos do ambiente de Desktop »
-------------------------------------------
ATALHO                            DESCRIÇÃO

01 - SUPER + 1..9               = Áreas de trabalho
02 - SUPER + Shift + Space      = Ativa/Desativa Janela flutuante
03 - SUPER + ←→↑↓               = Focar janela tileada por direção
04 - SUPER + Ctrl + ←→          = Ciclar foco entre janelas (tileadas e flutuantes)
05 - Ctrl + Alt + ←→  ou        = Circular entre áreas de trabalho
     Mouse 4 / Mouse 5
06 - ALT + Tab                  = Circular entre todas janelas
07 - SUPER + R                  = Entrar modo redimensionar janela (apenas flutuante)
     ←→↑↓                       = Redimensionar
     SHIFT + ←→↑↓               = Mover janela
     Esc                        = Sair modo redimensionar
08 - SUPER + Mouse Button 1     = Arrastar janela (apenas flutuante)
09 - SUPER + Mouse Button 2     = Modo redimensionar janela (apenas flutuante)
10 - SUPER + f                  = Tela cheia
11 - SUPER + s                  = Maximizar janela (toggle)
12 - SUPER + e                  = Alternar split vertical/horizontal
13 - SUPER + w                  = Agrupar/Desagrupar em abas
14 - SUPER + Tab                = Navegar entre abas
15 - SUPER + Shift + ←→↑↓       = Mover janela
16 - SUPER + q                  = Fechar janela
17 - SUPER + Shift + 1..9       = Mover janela para a área de trabalho
18 - Print                      = Capturar área selecionada
19 - SUPER + Print              = Capturar janela em foco
20 - SUPER + Shift + Print      = Capturar tela inteira
21 - SUPER + g                  = Iniciar/Pausar/Retomar gravação de tela
22 - SUPER + Shift + g          = Parar e salvar gravação de tela
23 - SUPER + ,                  = Abre/Fecha sidebar de notificações
24 - SUPER + BackSpace          = Oculta/Mostra Waybar top
25 - SUPER + y                  = Abre seletor para trocar wallpaper
26 - SUPER + Shift + t          = Abre o seletor de temas
27 - SUPER + Shift + a          = Abre o seletor de cores de destaque
28 - SUPER + Shift + l          = Escolhe o tempo de bloqueio por inatividade
29 - SUPER + Shift + w          = Configura a localização do clima
30 - SUPER + Shift + b          = Abre o seletor de brilho
31 - SUPER + F5                 = Altera entre tema Dark e Light do GTK
32 - SUPER + F6                 = Ativa/Desativa efeitos visuais
33 - SUPER + F1                 = Abrir Sobre o ARGVUS
34 - SUPER + L                  = Bloquear sistema
35 - SUPER + Shift + m          = Desligar/Ligar monitor (não é suspender)
36 - SUPER + Esc                = Sair do sistema
37 - SUPER + Shift + r          = Recarregar Hyprland
38 - SUPER + Alt + ↑/↓          = Mover barra de tarefas para topo/inferior

Atalhos de software »
------------------------------------------------
ATALHO                                 DESCRIÇÃO

39 - SUPER + Enter              = Terminal
40 - SUPER + Space              = Gerenciador de arquivos
41 - SUPER + Shift + d          = Menu de dispositivos removíveis
42 - SUPER + b                  = Navegador padrão
43 - SUPER + d                  = Lançador de programas
44 - SUPER + c                  = Calculadora
45 - SUPER + Ctrl + /           = Cheatsheets do Kitty
46 - SUPER + Shift + /          = Cheatsheets do Hyprland
47 - SUPER + h                  = Histórico no Clipboard
48 - SUPER + Shift + h          = Apagar histórico do Clipboard
49 - SUPER + p                  = Seletor de cores (Color Picker)
50 - SUPER + .                  = Emoji Picker
51 - ALT + SHIFT                = Alterna entre os layouts de teclado configurados
52 - SUPER + Alt + P            = Seletor de aplicativos padrão (argvus-default-apps)


Diretórios »
-----------------------------------------------

Configs do Argvus:      $HOME/.config/argvus/
Argvus por app:         $HOME/.config/argvus/<app>/  (hypr, waybar, kitty, quickshell, ...)
Overrides do Argvus:    $HOME/.config/<app>/  (override livre do usuário)
Logs do Hyprland:       $HOME/.local/state/hyprland/
Configs do Kitty:       $HOME/.config/argvus/kitty/
Configs da Waybar:      $HOME/.config/argvus/waybar/
Configs do Quickshell:  $HOME/.config/argvus/quickshell/
Argvus Storage:         $HOME/.config/argvus-storage/
