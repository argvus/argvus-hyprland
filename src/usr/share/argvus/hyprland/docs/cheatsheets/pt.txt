ARGVUS Cheatsheets
====================

Atalhos do ambiente de Desktop »
-------------------------------------------
ATALHO                          DESCRIÇÃO

01 - SUPER + 1..9               = Áreas de trabalho
02 - SUPER + Shift + Space      = Ativa/Desativa Janela flutuante
03 - SUPER + ←→↑↓               = Focar janela tileada por direção
04 - SUPER + Ctrl + ←→          = Ciclar foco entre janelas (tileadas e flutuantes)
05 - Ctrl + Alt + ←→  ou        = Circular entre áreas de trabalho
     Mouse 4 / Mouse 5
06 - SUPER + r                  = Entrar modo redimensionar janela (apenas flutuante)
     ←→↑↓                       = Redimensionar
     SHIFT + ←→↑↓               = Mover janela
     Esc                        = Sair modo redimensionar
07 - SUPER + Mouse Button 1     = Arrastar janela (apenas flutuante)
08 - SUPER + Mouse Button 2     = Modo redimensionar janela (apenas flutuante)
09 - SUPER + f                  = Tela cheia
10 - SUPER + s                  = Maximizar janela (toggle)
11 - SUPER + e                  = Alternar split vertical/horizontal
12 - SUPER + w                  = Agrupar/Desagrupar em abas
13 - SUPER + Tab                = Navegar entre abas
14 - SUPER + Shift + ←→↑↓       = Mover janela
15 - SUPER + q                  = Fechar janela
16 - SUPER + Shift + 1..9       = Mover janela para a área de trabalho
17 - Print                      = Capturar área selecionada
18 - SUPER + Print              = Capturar janela em foco
19 - SUPER + Shift + Print      = Capturar tela inteira
20 - SUPER + g                  = Iniciar/Pausar/Retomar gravação de tela
21 - SUPER + Shift + G          = Parar e salvar gravação de tela
22 - SUPER + ,                  = Abre/Fecha sidebar de notificações
23 - SUPER + BackSpace          = Oculta/Mostra Waybar top
24 - SUPER + y                  = Abre Control Center > Appearance > Wallpapers
25 - SUPER + Shift + T          = Abre o seletor de temas
26 - SUPER + Shift + M          = Abre o seletor de modos
27 - SUPER + Shift + L          = Escolhe o tempo de bloqueio por inatividade
28 - SUPER + Alt + w            = Ativa/Desativa manter acordado
29 - SUPER + Shift + W          = Configura a localização do clima
30 - SUPER + Shift + B          = Abre o seletor de brilho e a ação de luz noturna
31 - SUPER + F5                 = Alterna entre os temas ARGVUS Dark e ARGVUS Light
32 - SUPER + F6                 = Ativa/Desativa efeitos visuais
33 - SUPER + F1                 = Abrir Sobre o ARGVUS
34 - SUPER + l                  = Bloquear sistema
35 - SUPER + Shift + S          = Desligar/Ligar monitor (não é suspender)
36 - SUPER + Esc                = Sair do sistema
37 - SUPER + Shift + R          = Recarregar Hyprland
38 - SUPER + Alt + ↑/↓          = Mover barra de tarefas para topo/inferior

Atalhos de software »
------------------------------------------------
ATALHO                                 DESCRIÇÃO

39 - SUPER + Enter              = Terminal
40 - SUPER + Space              = Gerenciador de arquivos
41 - SUPER + Ctrl + Space       = Monitor do sistema
42 - SUPER + Shift + D          = Menu de dispositivos removíveis
43 - SUPER + b                  = Navegador padrão
44 - SUPER + d                  = Lançador de programas
45 - SUPER + c                  = Calculadora
46 - SUPER + Ctrl + /?          = Cheatsheets do Kitty
47 - SUPER + Shift + /?         = Cheatsheets do ARGVUS
48 - SUPER + h                  = Histórico no Clipboard
49 - SUPER + Shift + H          = Apagar histórico do Clipboard
50 - SUPER + p                  = Seletor de cores (Color Picker)
51 - SUPER + .                  = Emoji Picker
52 - Alt + Shift                = Alterna entre os layouts de teclado configurados
53 - SUPER + Alt + c            = Abre o ARGVUS Control Center
54 - SUPER + [                  = Terminal suspenso (dropdown; pressione de novo para ocultar)
55 - SUPER + o                  = Lista de projetos (argvus projects)
56 - SUPER + Alt + 1..9        = Projeto 1..9 (posições na lista de projetos)
57 - SUPER + Alt + s            = Seletor de hosts SSH (argvus ssh)
58 - SUPER + Alt + n            = Seletor de snippets (argvus snippets)
59 - SUPER + Alt + g            = Seletor de projetos e TUI de git (argvus git)
60 - SUPER + Shift + F          = ARGVUS Focus (Pomodoro e sessões de foco)
61 - SUPER + Shift + C          = ARGVUS Clock (relógio, temporizadores e alarmes)


Diretórios »
-----------------------------------------------

Configs do Argvus:      $HOME/.config/argvus/
ARGVUS por app:         $HOME/.config/argvus/data/<app>/  (hypr, waybar, quickshell, ...)
Overrides do ARGVUS:    $HOME/.config/<app>/  (override livre do usuário)
ARGVUS Log Session:     $HOME/.local/state/argvus/session.log
ARGVUS Storage:         $HOME/.config/argvus/data/removable-devices/
Configs da Waybar:      $HOME/.config/argvus/data/waybar/
Configs do Quickshell:  $HOME/.config/argvus/data/quickshell/
