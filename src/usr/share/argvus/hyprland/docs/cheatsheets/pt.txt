ARGVUS Cheatsheets
====================

Atalhos do ambiente de Desktop »
-------------------------------------------
ATALHO                          DESCRIÇÃO

01 - SUPER + 1..9               = Áreas de trabalho
02 - SUPER + Shift + Space      = Ativa/Desativa Janela flutuante
03 - SUPER + ←→↑↓               = Focar janela tileada por direção
04 - SUPER + Ctrl + ←→          = Ciclar foco entre janelas (tileadas e flutuantes)
05 - Ctrl + Alt + ←→  ou        = Circular entre áreas de trabalho
     Mouse 4 / Mouse 5
06 - Alt + Tab                  = Circular entre todas janelas
07 - SUPER + r                  = Entrar modo redimensionar janela (apenas flutuante)
     ←→↑↓                       = Redimensionar
     SHIFT + ←→↑↓               = Mover janela
     Esc                        = Sair modo redimensionar
08 - SUPER + Mouse Button 1     = Arrastar janela (apenas flutuante)
09 - SUPER + Mouse Button 2     = Modo redimensionar janela (apenas flutuante)
10 - SUPER + f                  = Tela cheia
11 - SUPER + s                  = Maximizar janela (toggle)
12 - SUPER + e                  = Alternar split vertical/horizontal
13 - SUPER + w                  = Agrupar/Desagrupar em abas
14 - SUPER + Tab                = Navegar entre abas
15 - SUPER + Shift + ←→↑↓       = Mover janela
16 - SUPER + q                  = Fechar janela
17 - SUPER + Shift + 1..9       = Mover janela para a área de trabalho
18 - Print                      = Capturar área selecionada
19 - SUPER + Print              = Capturar janela em foco
20 - SUPER + Shift + Print      = Capturar tela inteira
21 - SUPER + g                  = Iniciar/Pausar/Retomar gravação de tela
22 - SUPER + Shift + G          = Parar e salvar gravação de tela
23 - SUPER + ,                  = Abre/Fecha sidebar de notificações
24 - SUPER + BackSpace          = Oculta/Mostra Waybar top
25 - SUPER + y                  = Abre Control Center > Appearance > Wallpapers
26 - SUPER + Shift + T          = Abre o seletor de temas
27 - SUPER + Shift + M          = Abre o seletor de modos
28 - SUPER + Shift + L          = Escolhe o tempo de bloqueio por inatividade
29 - SUPER + Alt + w            = Ativa/Desativa manter acordado
30 - SUPER + Shift + W          = Configura a localização do clima
31 - SUPER + Shift + B          = Abre o seletor de brilho
32 - SUPER + F5                 = Altera entre tema Dark e Light do GTK
33 - SUPER + F6                 = Ativa/Desativa animações
34 - SUPER + F1                 = Abrir Sobre o ARGVUS
35 - SUPER + l                  = Bloquear sistema
36 - SUPER + Shift + S          = Desligar/Ligar monitor (não é suspender)
37 - SUPER + Esc                = Sair do sistema
38 - SUPER + Shift + R          = Recarregar Hyprland
39 - SUPER + Alt + ↑/↓          = Mover barra de tarefas para topo/inferior

Atalhos de software »
------------------------------------------------
ATALHO                                 DESCRIÇÃO

40 - SUPER + Enter              = Terminal
41 - SUPER + Space              = Gerenciador de arquivos
42 - SUPER + Ctrl + Space       = Monitor do sistema
43 - SUPER + Shift + D          = Menu de dispositivos removíveis
44 - SUPER + b                  = Navegador padrão
45 - SUPER + d                  = Lançador de programas
46 - SUPER + c                  = Calculadora
47 - SUPER + Ctrl + /?          = Cheatsheets do Kitty
48 - SUPER + Shift + /?         = Cheatsheets do ARGVUS
49 - SUPER + h                  = Histórico no Clipboard
50 - SUPER + Shift + H          = Apagar histórico do Clipboard
51 - SUPER + p                  = Seletor de cores (Color Picker)
52 - SUPER + .                  = Emoji Picker
53 - Alt + Shift                = Alterna entre os layouts de teclado configurados
54 - SUPER + Alt + c            = Abre o ARGVUS Control Center
55 - SUPER + [                  = Terminal suspenso (dropdown; pressione de novo para ocultar)
56 - SUPER + o                  = Lista de projetos (argvus-projects)
57 - SUPER + Alt + 1..9        = Projeto 1..9 (posições na lista de projetos)
58 - SUPER + Alt + s            = Seletor de hosts SSH (argvus-ssh)
59 - SUPER + Alt + n            = Seletor de snippets (argvus-snippets)


Diretórios »
-----------------------------------------------

Configs do Argvus:      $HOME/.config/argvus/
ARGVUS por app:         $HOME/.config/argvus/data/<app>/  (hypr, waybar, quickshell, ...)
Overrides do ARGVUS:    $HOME/.config/<app>/  (override livre do usuário)
ARGVUS Log Session:     $HOME/.local/state/argvus/session.log
ARGVUS Storage:         $HOME/.config/argvus/data/removable-devices/
Configs da Waybar:      $HOME/.config/argvus/data/waybar/
Configs do Quickshell:  $HOME/.config/argvus/data/quickshell/
