ARGVUS Cheatsheets
====================

Desktop Environment Shortcuts »
--------------------------------------------------
SHORTCUT                        DESCRIPTION

01 - SUPER + 1..9               = Workspaces
02 - SUPER + Shift + Space      = Enable/Disable Floating Window
03 - SUPER + ←→↑↓               = Focus tiled window by direction
04 - SUPER + Ctrl + ←→          = Cycle focus between windows (tiled and floating)
05 - Ctrl + Alt + ←→  or        = Moving between work areas
     Mouse 4 / Mouse 5
06 - Alt + Tab                  = Cycle through all windows
07 - SUPER + r                  = Enter window resize mode (floating window only)
     ←→↑↓                       = Resize
     SHIFT + ←→↑↓               = Move window
     Esc                        = Exit resize mode
08 - SUPER + Mouse Button 1     = Drag window (floating window only)
09 - SUPER + Mouse Button 2     = Window resize mode (floating window only)
10 - SUPER + f                  = Full screen window
11 - SUPER + s                  = Maximize window (toggle)
12 - SUPER + e                  = Split vertical/horizontal toggle
13 - SUPER + w                  = Group/Ungroup into tabs
14 - SUPER + Tab                = Navigate between tabs
15 - SUPER + Shift + ←→↑↓       = Move window
16 - SUPER + q                  = Close window
17 - SUPER + Shift + 1..9       = Move window to desktop
18 - Print                      = Capture selected area
19 - SUPER + Print              = Capture focused window
20 - SUPER + Shift + Print      = Capture entire screen
21 - SUPER + g                  = Start/Pause/Resume screen recording
22 - SUPER + Shift + G          = Stop and save screen recording
23 - SUPER + ,                  = Open/Close notification sidebar
24 - SUPER + BackSpace          = Toggle Waybar top
25 - SUPER + y                  = Opens Control Center > Appearance > Wallpapers
26 - SUPER + Shift + T          = Opens the selector themes
27 - SUPER + Shift + M          = Open the mode selector
28 - SUPER + Shift + L          = Choose the inactivity lock timeout
29 - SUPER + Alt + w            = Toggle Keep Awake
30 - SUPER + Shift + W          = Configures the weather location
31 - SUPER + Shift + B          = Opens the brightness selector
32 - SUPER + F5                 = Toggles between GTK Dark and Light themes
33 - SUPER + F6                 = Toggle animations
34 - SUPER + F1                 = Open About ARGVUS
35 - SUPER + l                  = Lock system
36 - SUPER + Shift + S          = Turn monitor off/on (not suspend system)
37 - SUPER + Esc                = Exit system
38 - SUPER + Shift + R          = Reload Hyprland
39 - SUPER + Alt + ↑/↓          = Move taskbar to top/bottom

Directories »
-----------------------------------------------

ARGVUS configs:        $HOME/.config/argvus/
ARGVUS per-app:        $HOME/.config/argvus/data/<app>/  (hypr, waybar, quickshell, ...)
ARGUVS overrides:      $HOME/.config/<app>/  (free user override)
ARGVUS session logs:   $HOME/.local/state/argvus/session.log
ARGVUS storage:        $HOME/.config/argvus/data/removable-devices/
Waybar configs:        $HOME/.config/argvus/data/waybar/
Quickshell configs:    $HOME/.config/argvus/data/quickshell/
