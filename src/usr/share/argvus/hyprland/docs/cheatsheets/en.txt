ARGVUS Cheatsheets
====================

Desktop Environment Shortcuts »
--------------------------------------------------
SHORTCUT                        DESCRIPTION

01 - SUPER + 1..9               = Workspaces
02 - SUPER + Shift + Space      = Enable/Disable Floating Window
03 - SUPER + ←→↑↓               = Focus tiled window by direction
04 - SUPER + Ctrl + ←→          = Cycle focus between windows (tiled and floating)
05 - Ctrl + Alt + ←→  or        = Moving between work areas
     Mouse 4 / Mouse 5
06 - SUPER + r                  = Enter window resize mode (floating window only)
     ←→↑↓                       = Resize
     SHIFT + ←→↑↓               = Move window
     Esc                        = Exit resize mode
07 - SUPER + Mouse Button 1     = Drag window (floating window only)
08 - SUPER + Mouse Button 2     = Window resize mode (floating window only)
09 - SUPER + f                  = Full screen window
10 - SUPER + s                  = Maximize window (toggle)
11 - SUPER + e                  = Split vertical/horizontal toggle
12 - SUPER + w                  = Group/Ungroup into tabs
13 - SUPER + Tab                = Navigate between tabs
14 - SUPER + Shift + ←→↑↓       = Move window
15 - SUPER + q                  = Close window
16 - SUPER + Shift + 1..9       = Move window to desktop
17 - Print                      = Capture selected area
18 - SUPER + Print              = Capture focused window
19 - SUPER + Shift + Print      = Capture entire screen
20 - SUPER + g                  = Start/Pause/Resume screen recording
21 - SUPER + Shift + G          = Stop and save screen recording
22 - SUPER + ,                  = Open/Close notification sidebar
23 - SUPER + BackSpace          = Toggle Waybar top
24 - SUPER + y                  = Opens Control Center > Appearance > Wallpapers
25 - SUPER + Shift + T          = Opens the selector themes
26 - SUPER + Shift + M          = Open the mode selector
27 - SUPER + Shift + L          = Choose the inactivity lock timeout
28 - SUPER + Alt + w            = Toggle Keep Awake
29 - SUPER + Shift + W          = Configures the weather location
30 - SUPER + Shift + B          = Opens the brightness selector
31 - SUPER + F5                 = Toggles between ARGVUS Dark and ARGVUS Light themes
32 - SUPER + F6                 = Toggle animations
33 - SUPER + F1                 = Open About ARGVUS
34 - SUPER + l                  = Lock system
35 - SUPER + Shift + S          = Turn monitor off/on (not suspend system)
36 - SUPER + Esc                = Exit system
37 - SUPER + Shift + R          = Reload Hyprland
38 - SUPER + Alt + ↑/↓          = Move taskbar to top/bottom

Directories »
-----------------------------------------------

ARGVUS configs:        $HOME/.config/argvus/
ARGVUS per-app:        $HOME/.config/argvus/data/<app>/  (hypr, waybar, quickshell, ...)
ARGUVS overrides:      $HOME/.config/<app>/  (free user override)
ARGVUS session logs:   $HOME/.local/state/argvus/session.log
ARGVUS storage:        $HOME/.config/argvus/data/removable-devices/
Waybar configs:        $HOME/.config/argvus/data/waybar/
Quickshell configs:    $HOME/.config/argvus/data/quickshell/
