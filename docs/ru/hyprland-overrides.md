title: Переопределения Hyprland
description: Настройте конфигурацию ARGVUS Hyprland без редактирования упакованных файлов.
---
ARGVUS поддерживает два различных способа настройки Hyprland. Их не следует путать:

- `~/.config/hypr/hyprland.lua` — это полная конфигурация пользователя. Когда она действительна и не является стандартным шаблоном Hyprland, `argvus start` запускает Hyprland с этим файлом вместо комплектной конфигурации.
- `~/.config/argvus/data/hypr/` содержит инкрементальные переопределения ARGVUS. Базовой остаётся комплектная конфигурация, и эти фрагменты загружаются в конце.

Для большинства настроек используйте инкрементальные переопределения ARGVUS. Они сохраняют значения по умолчанию ARGVUS, сгенерированное состояние и интеграцию сессий, доступные после обновлений пакета.

## Поддерживаемые файлы переопределений

Создайте каталог перед добавлением фрагмента:

```sh
mkdir -p ~/.config/argvus/data/hypr
```
Пакетная конфигурация загружает эти файлы в этом порядке, если они существуют:

```text
~/.config/argvus/data/hypr/monitors.lua
~/.config/argvus/data/hypr/rules.lua
~/.config/argvus/data/hypr/bindings.lua
~/.config/argvus/data/hypr/user.lua
```
Используйте файлы по ответственности:

- `monitors.lua` — дополнительные или заменяющие декларации мониторов.
- `rules.lua` — правила для окон и слоёв.
- `bindings.lua` — дополнительные привязки клавиш или пользовательские действия.
- `user.lua` — переменные окружения и другие Lua-настройки, которые не подходят к предыдущим категориям.

Фрагмент с ошибкой Lua не останавливает остальную конфигурацию. Hyprland пропускает этот файл, сообщает `ARGVUS: ignoring invalid user override` с его путем и ошибкой, и всё равно загружает оставшиеся фрагменты. Проверьте фрагмент с `luac -p` перед перезагрузкой.

Не редактируйте `/usr/share/argvus/hyprland/config/hyprland.lua`. Он принадлежит пакету и может быть заменен обновлением.

## Переопределения окружения

Используйте `user.lua` для значений окружения сессии:

```lua
-- ~/.config/argvus/data/hypr/user.lua
hl.env("MY_VARIABLE", "1")
```
Изменения в окружении влияют на приложения, запущенные в сессии. Выйдите из системы и войдите снова, если значение должно быть унаследовано всей сессией; одной перезагрузки композитора недостаточно для приложений, которые уже были запущены.

ARGVUS владеет `XDG_CONFIG_DIRS` и перестраивает его при каждой перезагрузке Hyprland, включая перезагрузки, вызванные переключением тем. Каждый каталог конфигурации ARGVUS появляется один раз, а записи, унаследованные от сессии, сохраняются после них без повторений, так что значение остается ограниченным. Сессии, запущенные ранними версиями, могут по-прежнему содержать дублирующиеся записи; если Kitty, `argvus terminal` или `argvus --control-center` не работают с `Out of buffer space calling sprintf`, выйдите и войдите снова, чтобы начать со свежим окружением.

## Добавление сочетания клавиш

Используйте `bindings.lua` для нового сочетания клавиш, которое не является частью манифеста сочетаний клавиш ARGVUS:

```lua
-- ~/.config/argvus/data/hypr/bindings.lua
hl.bind("SUPER + SHIFT + T", hl.dsp.exec_cmd("kitty"))
```
Используйте вспомогательные функции диспетчера ARGVUS Lua для действий композитора:

```lua
-- Focus the next window with a custom shortcut.
hl.bind("SUPER + CTRL + Tab", hl.dsp.group.next())
```
Привязка оценивается вместе с упакованной конфигурацией. Перед выбором комбинации проверьте наличие конфликтов с существующими ярлыками. Сохраняйте соответствующие параметры при определении специальных привязок, например:

```lua
hl.bind(
  "XF86AudioLowerVolume",
  hl.dsp.exec_cmd("wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-"),
  { locked = true, repeating = true }
)
```
Центр управления является предпочтительным способом изменения или отключения существующей привязки ARGVUS:

```sh
argvus control-center keybindings
```
Эти изменения хранятся канонически в `/keyboard_shortcuts` и материализуются в `~/.config/argvus/data/generated/hypr/keybindings.lua`. Ручное создание привязки в `bindings.lua` не добавляется в манифест Control Center и не управляется его действием восстановления.

## Полная нативная конфигурация Hyprland

`~/.config/hypr/hyprland.lua` не является файлом-оверлеем. Если вы его создадите, `argvus start` проверит его и использует как полную конфигурацию Hyprland:

```sh
mkdir -p ~/.config/hypr
cp /usr/share/argvus/hyprland/config/hyprland.lua ~/.config/hypr/hyprland.lua
```
Этот подход даёт полный контроль, но скопированный файл становится вашей ответственностью. Он может устаревать по мере изменения ARGVUS, а пользовательский файл, который опускает загрузчик ARGVUS или обработку состояния генерации, может потерять интеграцию с ARGVUS. Предпочитайте вышеупомянутые фрагментные файлы, если только вы намеренно не нуждаетесь в полной замене.

Стандартный файл Hyprland, содержащий `AUTOGENERATED HYPRLAND CONFIG`, игнорируется `argvus start`, поэтому его наличие не заменяет конфигурацию ARGVUS. Настроенный пользовательский файл выбирается только после проверки; если проверка не проходит, лаунчер возвращается к упакованному файлу.

## Применение и устранение неполадок

После изменения фрагмента Lua перезагрузите конфигурацию сессии:

```sh
argvus sessionctl reload
```
Проверьте полный файл Lua перед повторным входом:

```sh
luac -p ~/.config/hypr/hyprland.lua
Hyprland --verify-config --config ~/.config/hypr/hyprland.lua
```
Если конфигурация пользователя отклонена при запуске, проверьте:

```sh
grep -E "Hyprland Lua config|failed validation|using user Lua|fallback" \
  ~/.local/state/argvus/session.log
```
Упакованные исходники и вспомогательные файлы находятся в `/usr/share/argvus/hyprland/`. Сгенерированные файлы в `~/.config/argvus/data/generated/` являются производным состоянием; изменяйте соответствующие настройки или фрагменты-перекрытия вместо того, чтобы редактировать сгенерированные файлы напрямую.

См. [Сочетания клавиш](/docs/argvus-hyprland/keyboard-shortcuts/) для рабочего процесса Control Center] и [расположение файлов](/docs/reference/file-locations/) для полного справочника по путям конфигурации].

Мощность теневого рендеринга ограничена значениями 1–4 (по умолчанию 4) перед вызовом Hyprland, включая проекции старых эффектов. Это предотвращает ситуации, когда значения, принимаемые более старыми выпусками ARGVUS, препятствуют запуску на Hyprland 0.57.
