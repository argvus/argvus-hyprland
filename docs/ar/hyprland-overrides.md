:ﺎﻤﻬﻨﻴﺑ ﻂﻠﺨﻟﺍ ﺐﺠﻳ ﻻ﻿ .Hyprland ﺺﻴﺼﺨﺘﻟ ﻦﻴﺘﻔﻠﺘﺨﻣ ﻦﻴﺘﻘﻳﺮﻃ ARGVUS

-

هو تكوين المستخدم الكامل. عندما يكون صالحًا وليس قالب المخزون Hyprland،

 قم بتشغيل Hyprland بهذا الملف بدلاً من التكوين المعبأ.
-

 يحتوي على تجاوزات ARGVUS تزايدية. يظل التكوين المعبأ هو الأساس ويقوم بتحميل هذه الأجزاء في النهاية.

##                                                           ﺔﻣﻮﻋﺪﻤﻟﺍ ﺯﻭﺎﺠﺗ ﺕﺎﻔﻠﻣ

```sh
mkdir -p ~/.config/argvus/data/hypr
```

## ﺢﻴﺗﺎﻔﻤﻟﺍ ﺔﺣﻮﻟ ﺭﺎﺼﺘﺧﺍ ﺔﻓﺎﺿﺇ

Use

 للربط الجديد الذي ليس جزءًا من بيان ربط المفاتيح ARGVUS:

```lua
-- ~/.config/argvus/data/hypr/bindings.lua
hl.bind("SUPER + SHIFT + T", hl.dsp.exec_cmd("kitty"))
```

:ﻞﺻﻮﻤﻟﺍ ﻝﺎﻌﻓﻷ﻿ Lua ARGVUS ﻉﺯﻮﻣ ﻱﺪﻋﺎﺴﻣ ﻡﺪﺨﺘﺳﺍ

```lua
-- Focus the next window with a custom shortcut.
hl.bind("SUPER + CTRL + Tab", hl.dsp.group.next())
```

:ﻝﺎﺜﻤﻟﺍ ﻞﻴﺒﺳ ﻰﻠﻋ ،ﺔﺻﺎﺨﻟﺍ ﻂﺑﺍﻭﺮﻟﺍ ﻒﻳﺮﻌﺗ ﺪﻨﻋ ﺔﺒﺳﺎﻨﻤﻟﺍ ﺕﺍﺭﺎﻴﺨﻟﺍ

```lua
hl.bind(
  "XF86AudioLowerVolume",
  hl.dsp.exec_cmd("wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-"),
  { locked = true, repeating = true }
)
```

             :ﻲﻟﺎﺤﻟﺍ ARGVUS ﻂﺑﺭ ﻞﻴﻄﻌﺗ ﻭﺃ ﺮﻴﻴﻐﺘﻟ ﺔﻠﻀﻔﻤﻟﺍ ﺔﻘﻳﺮﻄﻟﺍ ﻮﻫ ﻢﻜﺤﺘﻟﺍ ﺰﻛﺮﻣ

```sh
argvus control-center keybindings
```

## ـﻟ ﺔﻠﻣﺎﻜﻟﺍ ﺔﻴﻠﺻﻷ﻿ﺍ ﺔﺌﻴﻬﺘﻟﺍ

 is not an overlay file. If you create it,

 يتحقق من صحته ويستخدمه كتكوين كامل Hyprland:

```sh
mkdir -p ~/.config/hypr
cp /usr/share/argvus/hyprland/config/hyprland.lua ~/.config/hypr/hyprland.lua
```

.ﻞﻣﺎﻛ ﻝﺍﺪﺒﺘﺳﻻ﻿ ﺓﺪﻤﻌﺘﻣ ﺔﺟﺎﺤﺑ ﺖﻨﻛ ﺍﺫﺇ ﻻ﻿ﺇ ﻩﻼ﻿ﻋﺃ ﻊﻄﻘﻟﺍ ﺕﺎﻔﻠﻣ ﻡﺍﺪﺨﺘﺳ

The stock Hyprland file containing  argvus start  ~/.config/hypr/hyprland.lua  bindings.lua  ~/.config/argvus/data/generated/hypr/keybindings.lua  /keyboard_shortcuts  bindings.lua  Out of buffer space calling sprintf  argvus --control-center  argvus terminal  `XDG_CONFIG_DIRS`  `argvus terminal`  `argvus --control-center`  `Out of buffer space calling sprintf`  `bindings.lua`  `/keyboard_shortcuts`  `~/.config/argvus/data/generated/hypr/keybindings.lua`  `bindings.lua`  `~/.config/hypr/hyprland.lua`  `argvus start` `AUTOGENERATED HYPRLAND CONFIG` is ignored by `argvus start`, so its presence does not replace the ARGVUS configuration. A customized user file is selected only after validation; if validation fails, the launcher falls back to the packaged file.
