제어 센터 → 로케일 및 지역 → 마우스 및 터치패드 를 열거나, `argvus control-center input`를 실행하세요.

## 마우스

마우스가 감지되면, 페이지에 다음 항목이 표시됩니다:

- `-1.0`에서 `1.0`까지의 감도;
- 적응형 또는 평면 가속 프로필;
- `0.1`에서 `10.0`까지의 스크롤 계수;
- 자연스러운 스크롤;
- 왼손잡이 버튼 레이아웃.

감도, 스크롤 계수 및 토글은 페이지가 열려 있는 동안 Hyprland에서 적용되며, 이후 전체 입력 상태가 저장됩니다. ARGVUS 입력 파일이 없으면 페이지는 현재 컴포지터 값을 읽습니다.

## 터치패드

터치패드가 감지되면, 페이지에 자연스러운 스크롤, 탭하여 클릭, 탭 후 끌기, 두 손가락 오른쪽 클릭, 입력 중 비활성화 옵션이 표시됩니다. 이러한 옵션은 실행 중인 세션이 터치패드를 보고할 때만 유용한 컨트롤로 표시됩니다.

## 하드웨어 종속 컨트롤

지원되는 장치에 대해서만 `ratbag`에 의해 지원되는 고급 마우스 컨트롤이 표시됩니다. ARGVUS는 모든 마우스가 DPI, 프로필 또는 폴링 변경을 지원한다고 주장하지 않습니다. 장치가 감지되지 않거나 선택적 장치 서비스가 사용 불가능한 경우, 이러한 컨트롤은 이 페이지에서 적용될 수 없습니다.

## 지속성과 초기화

설정은 사용자 상태로 저장되며, 세션을 위해 생성된 Hyprland 입력 조각이 재생성됩니다. 페이지에 재설정 기능이 있는 경우 사용하고, 생성된 조각을 직접 편집하지 마세요. 세션이 관련 장치 상태를 다시 로드할 수 없는 경우 설정은 현재 컴포지터에만 적용될 수 있습니다.

[제어 센터](/docs/components/argvus-control-center/)]와 [구성을 어디서 할지](/docs/user-guide/where-to-configure/)]를 참조하세요.
