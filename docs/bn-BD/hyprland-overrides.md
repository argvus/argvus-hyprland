---
title: Hyprland ওভাররাইড
description: প্যাকেজকৃত ফাইল সম্পাদনা ছাড়াই ARGVUS Hyprland কাস্টমাইজ করুন।
---

ARGVUS Hyprland কাস্টমাইজ করার দুটি ভিন্ন উপায় সমর্থন করে। এগুলি বিভ্রান্ত করা উচিত নয়:

- `~/.config/hypr/hyprland.lua` একটি সম্পূর্ণ ব্যবহারকারী কনফিগারেশন। যখন এটি বৈধ এবং স্টক Hyprland টেমপ্লেট নয়, তখন `argvus start` এই ফাইলের মাধ্যমে Hyprland চালু করে প্যাকেজ করা কনফিগারেশনের পরিবর্তে।
- `~/.config/argvus/data/hypr/` ধাপে ধাপে ARGVUS ওভাররাইড সমূহ ধারণ করে। প্যাকেজ করা কনফিগারেশন মূল থাকে এবং শেষে এই ফ্র্যাগমেন্টগুলোর লোড হয়।

বেশিরভাগ কাস্টমাইজেশনের জন্য, ইনক্রিমেন্টাল ARGVUS ওভাররাইড ব্যবহার করুন। এগুলি ARGVUS ডিফল্ট, জেনারেটেড স্টেট এবং সেশন ইন্টিগ্রেশন প্যাকেজ আপডেটের সময়ও অ্যাক্সেসযোগ্য রাখে।

## সমর্থিত ওভাররাইড ফাইলগুলি

একটি ফ্র্যাগমেন্ট যোগ করার আগে ডিরেক্টরি তৈরি করুন:

```sh
mkdir -p ~/.config/argvus/data/hypr
```

প্যাকেজ করা কনফিগারেশন এই ফাইলগুলি নিম্নলিখিত ক্রমে লোড করে যখন এগুলি উপস্থিত থাকে:

```text
~/.config/argvus/data/hypr/monitors.lua
~/.config/argvus/data/hypr/rules.lua
~/.config/argvus/data/hypr/bindings.lua
~/.config/argvus/data/hypr/user.lua
```

দায়িত্ব অনুযায়ী ফাইলগুলি ব্যবহার করুন:

- `monitors.lua` — অতিরিক্ত বা প্রতিস্থাপন মনিটর বিজ্ঞপ্তি।
- `rules.lua` — উইন্ডো এবং লেয়ার নিয়ম।
- `bindings.lua` — অতিরিক্ত কী বাইন্ডিং বা কাস্টম অ্যাকশন।
- `user.lua` — পরিবেশ ভেরিয়েবল এবং অন্যান্য লুয়া কনফিগারেশন যা পূর্ববর্তী বিভাগগুলিতে ফিট করে না।

একটি লুয়া ত্রুটি সহ ফ্র্যাগমেন্ট অন্যান্য কনফিগারেশন থেমে রাখে না। হাইপ্রল্যান্ড সেই ফাইলটি এড়িয়ে যায়, তার পথ এবং ত্রুটির সাথে `ARGVUS: ignoring invalid user override` রিপোর্ট করে, এবং এখনও অবশিষ্ট ফ্র্যাগমেন্টগুলি লোড করে। পুনরায় লোড করার আগে `luac -p` সহ একটি ফ্র্যাগমেন্ট পরীক্ষা করুন।

`/usr/share/argvus/hyprland/config/hyprland.lua` সম্পাদনা করবেন না। এটি প্যাকেজ-মালিকানাধীন এবং একটি আপডেট দ্বারা প্রতিস্থাপিত করা যেতে পারে।

## পরিবেশ ওভাররাইট

সেশন পরিবেশ মানের জন্য `user.lua` ব্যবহার করুন:

```lua
-- ~/.config/argvus/data/hypr/user.lua
hl.env("MY_VARIABLE", "1")
```

পরিবেশ পরিবর্তনগুলো সেই সেশনে শুরু হওয়া অ্যাপ্লিকেশনগুলিকে প্রভাবিত করে। যখন মানটি সম্পূর্ণ সেশনে উত্তরাধিকারী হতে হবে, তখন লগ আউট করে পুনরায় লগ ইন করুন; শুধুমাত্র একটি কম্পোজিটর পুনঃলোড ইতিমধ্যেই শুরু হওয়া অ্যাপ্লিকেশনগুলির জন্য যথেষ্ট নয়।

ARGVUS `XDG_CONFIG_DIRS` এর মালিক এবং তা প্রতিটি Hyprland রিলোডে পুনর্নির্মাণ করে, যার মধ্যে থিম সুইচের মাধ্যমে ট্রিগার হওয়া রিলোডও রয়েছে। প্রতিটি ARGVUS কনফিগারেশন ডিরেক্টরি একবার প্রদর্শিত হয়, এবং সেশন থেকে উত্তরাধিকারসূত্রে প্রাপ্ত এন্ট্রি তাদের পরে রাখা হয় পুনরাবৃত্তি ছাড়া, তাই মান সীমাবদ্ধ থাকে। পূর্বের সংস্করণের দ্বারা শুরু করা সেশন এখনও নকল এন্ট্রি বহন করতে পারে; যদি Kitty, `argvus terminal` বা `argvus --control-center` `Out of buffer space calling sprintf` এর সাথে ব্যর্থ হয়, তবে একটি পরিষ্কার পরিবেশ দিয়ে শুরু করতে লগ আউট এবং পুনরায় লগ ইন করুন।

## একটি কী-বাইন্ডিং যোগ করা

একটি নতুন বাইন্ডিং এর জন্য `bindings.lua` ব্যবহার করুন যা ARGVUS কী-বাইন্ডিং ম্যানিফেস্টের অংশ নয়:

```lua
-- ~/.config/argvus/data/hypr/bindings.lua
hl.bind("SUPER + SHIFT + T", hl.dsp.exec_cmd("kitty"))
```

কম্পোজিটর কাজের জন্য ARGVUS লুয়া ডিসপ্যাচার হেল্পার ব্যবহার করুন:

```lua
-- Focus the next window with a custom shortcut.
hl.bind("SUPER + CTRL + Tab", hl.dsp.group.next())
```

বাইন্ডিংটি প্যাকেজ করা কনফিগারেশনের সাথে একসাথে মূল্যায়ন করা হয়। একটি সংমিশ্রণ নির্বাচন করার আগে বিদ্যমান শর্টকাটগুলির সাথে সংঘর্ষ আছে কিনা পরীক্ষা করুন। বিশেষ বাইন্ডিং সংজ্ঞায়িত করার সময় উপযুক্ত বিকল্পগুলি সংরক্ষণ করুন, উদাহরণস্বরূপ:

```lua
hl.bind(
  "XF86AudioLowerVolume",
  hl.dsp.exec_cmd("wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-"),
  { locked = true, repeating = true }
)
```

নিয়ন্ত্রণ কেন্দ্র (Control Center) কোনও বিদ্যমান ARGVUS বাইন্ডিং পরিবর্তন বা নিষ্ক্রিয় করার জন্য পছন্দসই উপায়:

```sh
argvus control-center keybindings
```

সেই পরিবর্তনগুলো `/keyboard_shortcuts`-এর অধীনে ক্যানোনিক্যালি সংরক্ষিত হয় এবং `~/.config/argvus/data/generated/hypr/keybindings.lua`-এ বাস্তব রূপে প্রকাশিত হয়। `bindings.lua`-তে ম্যানুয়ালভাবে তৈরি করা একটি বাইন্ডিং কন্ট্রোল সেন্টার ম্যানিফেস্টে যোগ করা হয় না এবং এর রিস্টোর অ্যাকশন দ্বারা পরিচালিত হয় না।

## সম্পূর্ণ নেটিভ Hyprland কনফিগারেশন

`~/.config/hypr/hyprland.lua` একটি ওভারলে ফাইল নয়। যদি আপনি এটি তৈরি করেন, `argvus start` এটি যাচাই করে এবং এটি সম্পূর্ণ Hyprland কনফিগারেশন হিসেবে ব্যবহার করে:

```sh
mkdir -p ~/.config/hypr
cp /usr/share/argvus/hyprland/config/hyprland.lua ~/.config/hypr/hyprland.lua
```

এই পদ্ধতিতে সম্পূর্ণ নিয়ন্ত্রণ পাওয়া যায়, কিন্তু অনুলিপি করা ফাইলটি আপনার দায়িত্ব হয়ে যায়। এটি ARGVUS পরিবর্তিত হওয়ার সাথে সাথে পুরোনো হয়ে যেতে পারে, এবং একটি কাস্টম ফাইল যা ARGVUS লোডার বা জেনারেট হওয়া-স্টেট পরিচালনা বাদ দেয়, ARGVUS ইন্টিগ্রেশন হারাতে পারে। যখন না আপনার সচেতনভাবে একটি সম্পূর্ণ প্রতিস্থাপন প্রয়োজন হয়, তখন উপরের ফ্র্যাগমেন্ট ফাইলগুলিই বেছে নিন।

`AUTOGENERATED HYPRLAND CONFIG` ধারণকারী স্টক Hyprland ফাইলটি `argvus start` দ্বারা উপেক্ষা করা হয়, তাই এটির উপস্থিতি ARGVUS কনফিগারেশনটি প্রতিস্থাপন করে না। একটি কাস্টমাইজড ব্যবহারকারী ফাইল শুধুমাত্র যাচাইয়ের পরে নির্বাচিত হয়; যদি যাচাই ব্যর্থ হয়, লঞ্চার প্যাকেজকৃত ফাইলে ফিরে আসে।

## প্রয়োগ করুন এবং সমস্যা সমাধান করুন

একটি Lua ফ্র্যাগমেন্ট পরিবর্তনের পরে, সেশনের কনফিগারেশন পুনরায় লোড করুন:

```sh
argvus sessionctl reload
```

আবার লগইন করার আগে একটি সম্পূর্ণ লুয়া ফাইল যাচাই করুন:

```sh
luac -p ~/.config/hypr/hyprland.lua
Hyprland --verify-config --config ~/.config/hypr/hyprland.lua
```

যদি স্টার্টআপের সময় ব্যবহারকারীর কনফিগারেশন প্রত্যাখ্যান করা হয়, পরিদর্শন করুন:

```sh
grep -E "Hyprland Lua config|failed validation|using user Lua|fallback" \
  ~/.local/state/argvus/session.log
```

প্যাকেজকৃত সোর্স এবং হেল্পারগুলি রয়েছে `/usr/share/argvus/hyprland/` এর অধীনে। `~/.config/argvus/data/generated/` এর অধীনে উত্পন্ন ফাইলগুলি হলো প্রাপ্ত অবস্থা; উত্পন্ন আউটপুট সরাসরি সম্পাদনা করার পরিবর্তে সংশ্লিষ্ট সেটিং বা আংশিক ওভাররাইড সম্পাদনা করুন।

নিয়ন্ত্রণ কেন্দ্রের ওয়ার্কফ্লোর জন্য [কীবোর্ড শর্টকাট](/docs/argvus-hyprland/keyboard-shortcuts/) এবং সম্পূর্ণ কনফিগারেশন পাথ রেফারেন্সের জন্য [ফাইল অবস্থান](/docs/reference/file-locations/) দেখুন।

হাইপ্রল্যান্ড কল করার আগে ছায়া রেন্ডার পাওয়ার ১–৪ (ডিফল্ট ৪) এ সীমাবদ্ধ করা হয়, যার মধ্যে রয়েছে লিগ্যাসি ইফেক্ট প্রজেকশনও। এটি পুরনো ARGVUS রিলিজ দ্বারা গ্রহণযোগ্য মানগুলো হাইপ্রল্যান্ড 0.57-এ স্টার্টআপ ব্লক করা থেকে রোধ করে।
