---
title: Hyprland のオーバーライド
description: パッケージ化されたファイルを編集せずに、ARGVUS Hyprland の設定をカスタマイズします。
---
ARGVUSは、Hyprlandをカスタマイズするために2つの異なる方法をサポートしています。これらは混同してはいけません。

- `~/.config/hypr/hyprland.lua`は完全なユーザー設定です。有効であり、標準のHyprlandテンプレートでない場合、`argvus start`は、このファイルを使用してパッケージ化された設定の代わりにHyprlandを起動します。
- `~/.config/argvus/data/hypr/`は、増分的なARGVUSオーバーライドを含みます。パッケージ化された設定がベースとして残り、これらのフラグメントを最後にロードします。

ほとんどのカスタマイズには、増分的なARGVUSオーバーライドを使用してください。これにより、ARGVUSのデフォルト、生成された状態、セッション統合がパッケージの更新後も利用可能なまま保持されます。

## サポートされているオーバーライドファイル

フラグメントを追加する前にディレクトリを作成してください。

```sh
mkdir -p ~/.config/argvus/data/hypr
```
パッケージ化された設定は、これらのファイルが存在する場合、次の順序で読み込みます：

```text
~/.config/argvus/data/hypr/monitors.lua
~/.config/argvus/data/hypr/rules.lua
~/.config/argvus/data/hypr/bindings.lua
~/.config/argvus/data/hypr/user.lua
```
ファイルは責任ごとに使用してください:

- `monitors.lua` — 追加または置換用のモニター宣言。
- `rules.lua` — ウィンドウおよびレイヤーのルール。
- `bindings.lua` — 追加のキーバインディングまたはカスタムアクション。
- `user.lua` — 環境変数や前述のカテゴリに当てはまらないその他のLua構成。

Luaエラーを含むフラグメントがあっても、残りの設定は停止しません。Hyprlandはそのファイルをスキップし、パスとエラーを`ARGVUS: ignoring invalid user override`で報告し、残りのフラグメントは引き続き読み込みます。リロードする前に`luac -p`を含むフラグメントを確認してください。

`/usr/share/argvus/hyprland/config/hyprland.lua`を編集しないでください。それはパッケージ管理下にあり、アップデートによって置き換えられる可能性があります。

## 環境オーバーライド

セッション環境値には`user.lua`を使用してください:

```lua
-- ~/.config/argvus/data/hypr/user.lua
hl.env("MY_VARIABLE", "1")
```
環境の変更はセッションによって起動されたアプリケーションに影響します。値をセッション全体で引き継ぐ必要がある場合は、ログアウトして再度ログインしてください。アプリケーションが既に起動している場合、コンポジタのリロードだけでは不十分です。

ARGVUSは`XDG_CONFIG_DIRS`を所有しており、Hyprlandのリロード時にはテーマ切り替えによるリロードを含め、毎回再構築します。各ARGVUS設定ディレクトリは一度だけ表示され、セッションから引き継がれたエントリはその後に重複せず保持されるため、値は制約されます。以前のバージョンで開始されたセッションでは、重複したエントリが残る場合があります。Kitty、`argvus terminal`、または`argvus --control-center`が`Out of buffer space calling sprintf`で失敗した場合は、ログアウトして再度ログインし、クリーンな環境で開始してください。

## キーバインディングの追加

ARGVUSのキーバインディングマニフェストに含まれていない新しいバインディングには`bindings.lua`を使用してください:

```lua
-- ~/.config/argvus/data/hypr/bindings.lua
hl.bind("SUPER + SHIFT + T", hl.dsp.exec_cmd("kitty"))
```
コンポジター操作のためにARGVUS Luaディスパッチャーヘルパーを使用してください:

```lua
-- Focus the next window with a custom shortcut.
hl.bind("SUPER + CTRL + Tab", hl.dsp.group.next())
```
バインディングは、パッケージ化された設定と一緒に評価されます。組み合わせを選ぶ前に既存のショートカットとの競合がないか確認してください。特別なバインディングを定義する際には、適切なオプションを保持してください。例えば:

```lua
hl.bind(
  "XF86AudioLowerVolume",
  hl.dsp.exec_cmd("wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-"),
  { locked = true, repeating = true }
)
```
コントロールセンターは、既存のARGVUSバインディングを変更または無効にするための推奨方法です。

```sh
argvus control-center keybindings
```
これらの変更は `/keyboard_shortcuts` の下に標準的に保存され、`~/.config/argvus/data/generated/hypr/keybindings.lua` に具体化されます。`bindings.lua` で手動で作成されたバインディングは、コントロールセンターマニフェストに追加されず、その復元アクションによって管理されません。

## 完全なネイティブ Hyprland 設定

`~/.config/hypr/hyprland.lua` はオーバーレイファイルではありません。これを作成すると、`argvus start` がそれを検証し、完全な Hyprland 設定として使用します:

```sh
mkdir -p ~/.config/hypr
cp /usr/share/argvus/hyprland/config/hyprland.lua ~/.config/hypr/hyprland.lua
```
このアプローチでは完全な制御が可能ですが、コピーされたファイルはあなたの責任となります。ARGVUSが変更されると古くなる可能性があり、ARGVUSローダーや生成状態の処理を省略したカスタムファイルはARGVUSの統合を失うことがあります。完全な置き換えが意図的に必要な場合を除き、上記のフラグメントファイルを優先してください。

`AUTOGENERATED HYPRLAND CONFIG`を含む標準のHyprlandファイルは`argvus start`によって無視されるため、その存在はARGVUSの設定を置き換えません。カスタマイズされたユーザーファイルは検証後にのみ選択されます。検証に失敗した場合、ランチャーはパッケージされたファイルに戻ります。

## 適用とトラブルシューティング

Luaフラグメントを変更した後、セッション設定をリロードしてください:

```sh
argvus sessionctl reload
```
再度ログインする前に、Luaファイル全体を検証してください:

```sh
luac -p ~/.config/hypr/hyprland.lua
Hyprland --verify-config --config ~/.config/hypr/hyprland.lua
```
起動中にユーザー設定が拒否された場合、次を確認してください:

```sh
grep -E "Hyprland Lua config|failed validation|using user Lua|fallback" \
  ~/.local/state/argvus/session.log
```
パッケージ化されたソースとヘルパーは`/usr/share/argvus/hyprland/`の下にあります。`~/.config/argvus/data/generated/`の下に生成されたファイルは派生状態です。生成された出力を直接編集するのではなく、所有する設定またはオーバーライドフラグメントを編集してください。

Control Centerワークフローについては[Keyboard shortcuts](/docs/argvus-hyprland/keyboard-shortcuts/)]を参照し、完全な設定パスの参照については[file locations](/docs/reference/file-locations/)]を参照してください。

ShadowレンダリングパワーはHyprlandを呼び出す前に1〜4（デフォルトは4）に制限されます。これには従来のエフェクト投影も含まれます。これは、古いARGVUSリリースで受け入れられる値が、Hyprland 0.57の起動を妨げることを防ぐためです。
