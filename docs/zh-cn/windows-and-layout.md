title: 窗口和布局
description: 了解 ARGVUS 中的间隙、边界、模式和面板空间。
---
ARGVUS 使用 Hyprland 进行平铺和浮动窗口放置。面向用户的布局控制位于三个控制中心页面：**控制中心 → 外观 → 任务栏**（位置、空间和图标）、**控制中心 → 桌面与输入 → Hyprland → 窗口 → 空间** 和 **控制中心 → 桌面与输入 → Hyprland → 边框**。

## 概念

```text
┌────────────────────────────────────┐
│          outer space / panel       │
│   ┌────────────┐  inner  ┌──────┐  │
│   │   window   │   gap    │window│  │
│   └────────────┘          └──────┘  │
│     border around each window       │
└────────────────────────────────────┘
```

- **窗口间隙** 是指平铺窗口与平铺布局外边缘之间的空间。
- **任务栏或外壳间距** 是指桌面表面（如任务栏和面板）周围的边距。这与窗口间隙的值不同。
- **边框** 是绘制在窗口周围的可见边缘。**边缘厚度** 控制外观页面显示的边框宽度。
- **圆角** 是所选视觉模式的一部分。它改变窗口的角形状，而不是移动窗口。
- **面板预留和可见边距** 是独立的问题：面板可以占用空间或视觉上使用空间，同时 Hyprland 仍然根据活动间距状态布局窗口。

## 粘性模式与间距模式

捆绑的主题模式提供了两种起始几何布局:

| 模式 | 窗口行为 | 表面处理 |
| --- | --- | --- |
| 粘性 | 内部间距 `2`，外部间距默认 `0` | 方形、紧凑且靠近屏幕边缘 |
| 间隔 | 内部间距 `10`，外部间距默认 `18` | 圆角、有阴影且更宽敞；任务栏/外壳边距默认 `18` |

这些是默认值，而非限制。窗口间距和任务栏间距页面可以独立存储窗口间距和任务栏边距。更改主题或模式可能会产生不同的有效布局值。

## 布局控件

每个控件都是独立的，并位于此处列出的页面上：

- **任务栏 → 位置** — 任务栏位置，顶部或底部边缘。
- **任务栏 → 间距** — 任务栏顶部、左侧、右侧和底部的边距，每个从 `0` 到 `100`。Sticky 默认将底部边距设置为 `2`；Spaced 使用 `18`。
- **任务栏 → 图标** — 任务栏工具组是否使用自动或始终展开行为。
- **Hyprland → 窗口 → 间距** — 内部间隙和外部顶部/左侧/右侧/底部间隙，每个从 `0` 到 `100`。
- **Hyprland → 边框** — 常规边框：启用圆角；启用时，圆角可从 `2` 到 `10` 选择。边缘厚度也在此处设置，从 `0` 到 `10`。
- **Hyprland → 边框 → 阴影** — 窗口阴影，默认关闭。它设置范围、渲染强度、尖角、偏移和缩放，其颜色遵循主题强调色并带有透明度 `99`，除非输入了颜色。

这些值被写入 ARGVUS 外观状态，`argvus-config` 将它们投射到生成的 Hyprland 文件中，然后会话再应用这些文件。任务栏边距会改变 shell 窗口的位置；外部窗口间隙会改变平铺窗口区域。它们可以产生类似的视觉距离，但改变其中一个不会改变另一个。

## 窗口和工作区

Hyprland 会在活动工作区安排平铺窗口。ARGVUS 也支持浮动实用窗口；`SUPER + SHIFT + Space` 可在平铺布局和浮动布局之间切换当前窗口。工作区移动和窗口焦点由活动快捷键清单控制；详见 [Keyboard shortcuts](/docs/argvus-hyprland/keyboard-shortcuts/)。

打包的配置将控制中心、贪吃蛇和磁盘使用分析器以浮动居中的窗口打开。磁盘使用分析器使用与任务栏内存弹出窗口相同的初始几何形状 `1399 × 920`，当窗口打开时，由其窗口类规则应用。ARGVUS Focus 和 ARGVUS Clock 是 GTK 层壳弹出窗口，固定在任务栏旁边，因此它们不是平铺窗口，也不使用 Hyprland 窗口规则。时钟闹钟卡是一个单独的层面 (`argvus-clock-alarm`)。

控制面板在其模态窗口打开时使用全屏层面。打包规则使 Polkit 代理、GTK 门户和 KDialog 窗口浮动、居中并固定，这样面板启动的对话框可以保持在模态窗口之上并能够接收输入。

`hyprpicker` 与 `SUPER + P` 一起打开时，不使用 Hyprland 动画。此例外仅影响颜色选择器；其他动画继续遵循全局设置。

### 浏览器和 IDE 的工作区放置

在全新安装的系统上默认没有定义任何窗口规则。您可以在 argvus-config 下的 `hyprland.window_rules` 为每个应用程序添加自己的工作区放置规则，例如：

```sh
argvus config get hyprland.window_rules
argvus config set hyprland.window_rules.browser.workspace 3
```
每条规则都有一个  `argvus-config` `workspace` （从 1 到 10）和一个 `classes` 列表。`classes` 中的条目是与窗口类匹配的正则表达式（区分大小写），例如 `[Cc]ode.*` 或 `jetbrains-.*`。只接受字母、数字和 `._*+?-[]()|^$`。`argvus-config` 将规则写入 `generated/hypr/window-rules.lua`，Hyprland 配置会加载该文件。要在不更改默认值的情况下替换规则，请在你的 ARGVUS 数据目录中添加 `hl.window_rule` 调用到 `rules.lua`；这些会在生成的规则之后加载。

## 首先要更改的内容

- 如果窗口显得拥挤，请增加窗口间距或使用间隔模式。
- 如果窗口看起来离屏幕边缘太远，请减少外部/任务栏间距或使用粘滞模式。
- 如果在更改任务栏位置后任务栏出现未对齐情况，请检查任务栏位置以及四个任务栏/外壳边距。
- 如果窗口与视觉面板重叠，请在更改窗口间距前检查面板和任务栏布局设置。

更改通过 ARGVUS 外观/会话集成应用。在页面可用时使用重置操作；不要直接编辑生成的 Hyprland 文件。

## 窗口晃动

打开 **桌面与输入 → Hyprland → 动画 → 窗口** 并使用 **晃动** 控件。搜索 `wobble`，或直接打开页面：

```sh
argvus control-center hyprland animations windows
```
Wobble 默认情况下是禁用的。其 ARGVUS 默认值为：刚度 `100`、阻尼 `10`、质量 `1`、强度 `1` 和网格分辨率 `8`。刚度和质量接受 `0.0001–1000`，阻尼 `0–1000`，强度 `0–2`，网格为整数 `2–32`。更高的网格分辨率会增加渲染成本。使用箭头键调整数值，或按 Enter 键输入数值。**恢复 Wobble 默认值** 会更改草稿；**应用** 会保存所有待处理的动画修改并重新加载 Hyprland 一次，无需重启会话。在动画中返回会保留共享草稿。

全局动画开关在保留各自设置的同时抑制 Wobble。规范值存储在 ARGVUS 状态下的 `effects.wobble_*`；`hypr/state.lua` 是生成的，不得手动编辑。

这需要 Hyprland **0.57.0 或更新版本**，由 `argvus-hyprland` 的软件包依赖强制执行。版本 0.56 不支持此配置。强度最大值遵循 [发布的 0.57.0 源代码 ](https://github.com/hyprwm/Hyprland/blob/v0.57.0/src/config/values/ConfigValues.cpp)，限制为 `2`，即使较新的文档可能列出 `3`]。

## 全局窗口模式

打开 **控制中心 → 桌面与输入 → Hyprland → 窗口 → 模式** 并选择 **平铺窗口（默认）** 或 **浮动窗口**。在任务栏工具组的窗口模式图标中也可以使用相同的选择器。

该偏好适用于每个显示器和工作区，并在注销后仍会被记住。浮动会转换现有的应用程序窗口和新打开的窗口。平铺仅恢复由此策略转换的窗口；已经处于浮动状态的对话框和其他窗口保持浮动。在浮动模式激活时明确固定的窗口也会保持浮动，以保留其固定状态。平铺布局会重新计算；其之前的精确分割树不会被恢复。

`SUPER + SHIFT + Space` 在平铺模式下保持其正常的每窗口行为。在浮动模式下，它不会将窗口切换回平铺。面板、任务栏和通知栏是层壳表面，不受影响。全屏模式继续使用 Hyprland 的正常行为；ARGVUS 最大化在 Spaced 中保留边距。

规范首选项是在 $XDG_CONFIG_HOME/argvus/config/hyprland.json 中的 `/hyprland/window_mode`。其生成的投影是  `$XDG_CONFIG_HOME/argvus/config/hyprland.json` `data/generated/hypr/window-mode.lua`；请勿编辑。每个窗口的还原注册表位于 `$XDG_RUNTIME_DIR/argvus` 下，以组合器实例为范围，并在配置重新加载时保持有效。在新会话中不会重复使用。

如果应用程序处于待定状态或失败，界面会将其与保存的首选项区分开。再次选择该选项以重试。没有组合器时，该首选项会为下次登录保存。

## 窗口按钮和应用程序栏

浮动模式为普通应用窗口添加了带有 **最小化**、**最大化 / 还原** 和 **关闭** 按钮的 ARGVUS 标题栏。双击标题栏可切换最大化。在平铺和全屏模式下，额外的装饰会被隐藏。自行绘制控件的应用程序可能会同时显示两个工具栏；统一的 ARGVUS 控件是刻意为之。

在每个显示器上都会出现第二个 Waybar，位于主任务栏的相对边缘。它只列出该显示器当前工作区的窗口，包括最小化的窗口。隐藏的分组标签不会创建额外条目。最小化的条目保留其原始的显示器/工作区关联。点击非活跃窗口可以激活它，点击活跃窗口可以将其最小化，点击最小化的窗口可以将其还原；其上下文菜单提供还原、最小化、最大化/还原和关闭选项。未知应用程序图标将回退为窗口符号。激活或还原条目会保留指针位置。辅助栏使用有效的主 CSS（颜色、字体、边框和圆角），其高度以及在相对边缘的镜像边距相同。

`SUPER + Alt + Up` 将主栏放在顶部，窗口栏放在底部。`SUPER + Alt + Down` 则相反。重复一个方向将保持位置不变。平铺模式只有主栏。返回到平铺模式会在移除窗口栏之前恢复所有最小化的窗口，然后保留原来的平铺/浮动策略。

最小化使用保留的 `special:argvus-minimized` 工作区。请勿手动使用该工作区。`argvus windows service` 进程在特定合成器实例的运行时注册表中，在 `$XDG_RUNTIME_DIR/argvus` 下记录身份、原始工作区/显示器、几何形状、全屏/最大化和固定状态。记录在服务重启或配置重新加载后仍然存在，但不会跨合成器会话。关闭窗口会删除其记录。如果显示器消失，恢复将使用可用的输出。缺失或恢复栏失败会阻止新的最小化；恢复失败会保留记录和恢复栏。

会话拥有 `argvus-windows.service` 和 `argvus-window-bar.service`。后者保持其 Waybar 子进程在 Tile 中休眠。hyprbars 插件由 `argvus-hyprland` 打包，为 x86_64 上的 Hyprland 0.57.0 ABI 构建；它不是在用户的主目录中编译。请在更新合成器 ABI 后重新构建该插件。命令：`argvus windows list --json`、`watch --json`、`position top|bottom`、`restore-all` 和 `minimize|restore|activate|maximize|close ADDRESS`。窗口地址来自列表。`position top --persist` 存储/投影偏好设置而无需重启主栏。配置和运行时错误详情会记录到日志中；可见的操作失败也会显示翻译后的通知。

在 **Spaced + Floating** 模式下，窗口会遵循外部间隙和两个栏位预留的区域。边界包括边框和标题，标题位于同一窗口边框内。通过 ARGVUS 控制最大化时，会用边距填充该区域；恢复时会拾回之前的几何状态，包括服务重启后。全屏模式仍使用整个输出区域。浮动窗口可能重叠；铺砖模式中的内部间隙不会将它们分开。

`SUPER + Alt + Space` 切换全局平铺/浮动模式，使用与任务栏和控制中心相同的偏好设置。等效命令是 `argvus config window-mode toggle`。并发调用会序列化；即使应用程序待处理，切换也会使用已保存的偏好设置。快捷键可以在键盘快捷方式中更改或禁用；`SUPER + Shift + Space` 保持其单个窗口操作。
