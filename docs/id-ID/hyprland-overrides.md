---
title: Hyprland menimpa
description: Sesuaikan konfigurasi ARGVUS Hyprland tanpa mengedit file yang dikemas.
---

ARGVUS mendukung dua cara berbeda untuk menyesuaikan Hyprland. Cara ini tidak boleh disamakan:

- `~/.config/hypr/hyprland.lua` adalah konfigurasi pengguna lengkap. Ketika valid dan bukan template Hyprland bawaan, `argvus start` meluncurkan Hyprland dengan file ini alih-alih konfigurasi yang dikemas.
- `~/.config/argvus/data/hypr/` berisi override ARGVUS bertahap. Konfigurasi yang dikemas tetap menjadi dasar dan memuat fragmen ini di akhir.

Untuk sebagian besar kustomisasi, gunakan override ARGVUS bertahap. Mereka mempertahankan default ARGVUS, status yang dihasilkan, dan integrasi sesi yang tersedia di seluruh pembaruan paket.

## File override yang didukung

Buat direktori sebelum menambahkan fragmen:

```sh
mkdir -p ~/.config/argvus/data/hypr
```

Konfigurasi yang dikemas memuat file-file ini dalam urutan ini saat ada:

```text
~/.config/argvus/data/hypr/monitors.lua
~/.config/argvus/data/hypr/rules.lua
~/.config/argvus/data/hypr/bindings.lua
~/.config/argvus/data/hypr/user.lua
```

Gunakan file sesuai tanggung jawab:

-

 — additional or replacement monitor declarations.
-

 — window and layer rules.
-

 — additional keybindings or custom actions.
-

 — variabel lingkungan dan konfigurasi Lua lainnya yang tidak sesuai dengan kategori sebelumnya.

Fragmen dengan kesalahan Lua tidak menghentikan konfigurasi lainnya. Hyprland melewati file tersebut, melaporkan  user.lua  bindings.lua  rules.lua  `monitors.lua`  `rules.lua`  `bindings.lua`  `user.lua` `ARGVUS: ignoring invalid user override` dengan jalurnya dan kesalahannya, dan tetap memuat fragmen yang tersisa. Periksa fragmen dengan `luac -p` sebelum memuat ulang.

Jangan mengedit `/usr/share/argvus/hyprland/config/hyprland.lua`. Itu dimiliki paket dan dapat diganti oleh pembaruan.

## Penggantian lingkungan

Gunakan `user.lua` untuk nilai lingkungan sesi:

```lua
-- ~/.config/argvus/data/hypr/user.lua
hl.env("MY_VARIABLE", "1")
```

Perubahan lingkungan memengaruhi aplikasi yang dijalankan oleh sesi. Keluar dan masuk kembali ketika nilai harus diwarisi oleh seluruh sesi; memuat ulang compositor saja tidak cukup untuk aplikasi yang sudah dijalankan.

ARGVUS memiliki `XDG_CONFIG_DIRS` dan membangunnya kembali setiap kali Hyprland dimuat ulang, termasuk pemuatan ulang yang dipicu oleh pergantian tema. Setiap direktori konfigurasi ARGVUS muncul sekali, dan entri yang diwariskan dari sesi disimpan setelahnya tanpa pengulangan, sehingga nilainya tetap terbatas. Sesi yang dimulai oleh versi sebelumnya mungkin masih membawa entri yang duplikat; jika Kitty, `argvus terminal` atau `argvus --control-center` gagal dengan `Out of buffer space calling sprintf`, keluar dan masuk kembali untuk memulai dengan lingkungan yang bersih.

## Menambahkan keybinding

Use

 for a new binding that is not part of the ARGVUS keybinding manifest:

```lua
-- ~/.config/argvus/data/hypr/bindings.lua
hl.bind("SUPER + SHIFT + T", hl.dsp.exec_cmd("kitty"))
```

Gunakan bantuan dispatcher Lua ARGVUS untuk tindakan kompositor:

```lua
-- Focus the next window with a custom shortcut.
hl.bind("SUPER + CTRL + Tab", hl.dsp.group.next())
```

Pengikatan dievaluasi bersama dengan konfigurasi yang dikemas. Periksa konflik dengan pintasan yang ada sebelum memilih kombinasi. Pertahankan opsi yang sesuai saat mendefinisikan pengikatan khusus, misalnya:

```lua
hl.bind(
  "XF86AudioLowerVolume",
  hl.dsp.exec_cmd("wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-"),
  { locked = true, repeating = true }
)
```

Pusat Kontrol adalah cara yang disarankan untuk mengubah atau menonaktifkan pengikatan ARGVUS yang ada:

```sh
argvus control-center keybindings
```

Perubahan tersebut disimpan secara kanonik di bawah  `bindings.lua` `/keyboard_shortcuts` dan diwujudkan ke dalam `~/.config/argvus/data/generated/hypr/keybindings.lua`. Binding yang dibuat secara manual di `bindings.lua` tidak ditambahkan ke manifes Pusat Kontrol dan tidak dikelola oleh tindakan pemulihannya.

## Konfigurasi Hyprland asli penuh

`~/.config/hypr/hyprland.lua` bukan file overlay. Jika Anda membuatnya, `argvus start` memvalidasinya dan menggunakannya sebagai konfigurasi lengkap Hyprland:

```sh
mkdir -p ~/.config/hypr
cp /usr/share/argvus/hyprland/config/hyprland.lua ~/.config/hypr/hyprland.lua
```

Pendekatan ini memberikan kontrol penuh, tetapi file yang disalin menjadi tanggung jawab Anda. File ini bisa menjadi usang seiring perubahan ARGVUS, dan file khusus yang menghilangkan pemuat ARGVUS atau penanganan status yang dihasilkan dapat kehilangan integrasi ARGVUS. Lebih disarankan menggunakan file fragmen di atas kecuali Anda secara sengaja membutuhkan penggantian lengkap.

File Hyprland standar yang berisi `AUTOGENERATED HYPRLAND CONFIG` diabaikan oleh `argvus start`, sehingga kehadirannya tidak menggantikan konfigurasi ARGVUS. File pengguna yang disesuaikan hanya dipilih setelah validasi; jika validasi gagal, peluncur kembali menggunakan file yang dikemas.

## Terapkan dan tangani masalah

Setelah mengubah fragmen Lua, muat ulang konfigurasi sesi:

```sh
argvus sessionctl reload
```

Validasi file Lua lengkap sebelum masuk kembali:

```sh
luac -p ~/.config/hypr/hyprland.lua
Hyprland --verify-config --config ~/.config/hypr/hyprland.lua
```

Jika konfigurasi pengguna ditolak saat startup, periksa:

```sh
grep -E "Hyprland Lua config|failed validation|using user Lua|fallback" \
  ~/.local/state/argvus/session.log
```

Sumber yang dikemas dan pembantu berada di bawah `/usr/share/argvus/hyprland/`. File yang dihasilkan di bawah `~/.config/argvus/data/generated/` adalah keadaan turunan; edit pengaturan pemilik atau fragmen override daripada mengedit output yang dihasilkan secara langsung.

Lihat [Keyboard shortcuts](/docs/argvus-hyprland/keyboard-shortcuts/) untuk alur kerja Control Center dan [lokasi file](/docs/reference/file-locations/) untuk referensi jalur konfigurasi lengkap.

Daya render bayangan dibatasi pada 1–4 (default 4) sebelum memanggil Hyprland, termasuk proyeksi efek warisan. Ini mencegah nilai yang diterima oleh rilis ARGVUS lebih lama dari menghentikan startup di Hyprland 0.57.
